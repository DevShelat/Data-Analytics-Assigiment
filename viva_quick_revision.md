# Module 7 – 1-Minute Viva Revision

1. Python = high-level interpreted general-purpose language.
2. `if/elif/else` = decision making.
3. `for` = loop/iteration.
4. `while` = repeats while condition is true.
5. `%` = remainder.
6. `==` = equality comparison.
7. `=` = assignment.
8. `len()` = length.
9. `list` = ordered mutable collection.
10. `tuple` = ordered immutable collection.
11. `dict` = key-value collection.
12. `set` = unique unordered collection.
13. `append()` = adds one object.
14. `extend()` = adds elements of an iterable.
15. `pop()` = removes and returns an element.
16. `split()` = string to list.
17. `join()` = iterable of strings to one string.
18. `def` = function definition.
19. `return` = function result.
20. `import random` = access random module.
21. `random.choice()` = random item.
22. `random.shuffle()` = shuffle list in place.
23. `open()` = file access.
24. `try/except` = exception handling.
25. `finally` = cleanup/end code.
