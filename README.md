# Data Analytics – Module 7: Introduction to Python

This repository contains solutions and short viva explanations for the Module 7 Python assignment from the college assignment PDF.

## Files

- `assignment.py` — Python programs/functions for the coding questions.
- `theory_and_viva.md` — theory answers and quick explanations for understanding/viva preparation.

## How to run

Open `assignment.py` in Python, VS Code, IDLE, Jupyter or another Python environment and run the required question's section.

Some file-handling questions are intentionally shown as commented examples because they require a real `sample.txt` file.

## Viva approach

For each program, be able to explain:
1. What input is taken.
2. What condition/loop/function is used.
3. How the result is calculated.
4. What the important Python method/operator does.

The solutions follow the wording and sequence of Module 7 in the assignment PDF.
