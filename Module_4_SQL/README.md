# Data Analytics – Module 4 SQL Assignment

## Topic
**Working with Database using SQL**

This repository contains the SQL statements and written answers for Module 4 of the Data Analytics assignment.

## Files

- `assignment.sql` – SQL statements for Questions 1–7.
- `answers.md` – Written answers for Questions 1–12.

## Database

The assignment is based on the MarketCo contact management database.

Run the SQL statements in MySQL Workbench after selecting the database/schema used for the assignment.

Example:

```sql
USE Assignment;
```

If your schema has a different name, replace `Assignment` with your actual schema name.

## Important

Questions 1–3 create the Contact, Employee and ContactEmployee tables.

Questions 4–7 modify/query the existing assignment database.

Question 7 requires the query to be executed in MySQL Workbench so that the actual employee names returned by the database can be copied into the assignment.

The SQL file follows the questions in the college assignment PDF.
